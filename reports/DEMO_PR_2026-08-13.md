## Purpose

এই PR-টা শুধু **workflow demo** — user merge করে দেখবেন যে:

1. এজেন্ট শুধু **current branch**-এ কাজ করে (branch switch/create নেই, `main`-এ direct push নেই)।
2. প্রতি ধাপে `git add -A` → `git commit` → `git push origin arena/019ffc78-workplace-drive`।
3. PR খোলার আগে `gh pr list --head <branch>` চেক — open PR থাকলে নতুন PR না বানিয়ে শুধু push (existing PR auto-update)।
4. PR **merge/close** হয়ে গেলে ব্রাঞ্চ আবার free → **একই session থেকে** নতুন commit + push + নতুন PR খোলা যায়। তাই ব্রাঞ্চ কখনো "block" হয় না।
