## 2. WHAT THE PIPELINE DOES (re-runnable, no-edits)

`python3 scripts/d4_v21_avoidance.py --data-dir phase_f_forward` (numpy only; sklearn/xgboost optional)

1. **Load + dedup by id** across all daily folders (most-complete record wins), keep decided WIN/LOSS. 18 pairs.
2. **Data audit** — decided / any-indicator / indicator-complete (IC = rsi, atrPct, adx, bbBandwidth all numeric) per signal day.
3. **PART 1 — v2-features recap** on all rows; holdout auto-picked = newest day with ≥30 decided rows (here 2026-08-09). Regression check that the v2 ceiling stands (it does — §3).
4. **PART 2 — primary v2.1 run**, IC rows only, strictly chronological, **no hardcoded dates**:
   - **HOLDOUT** = newest day with ≥30 IC rows (auto-pick; `--holdout-day` overrides).
   - **TRAIN** = all IC rows strictly before the holdout day.
   - **FULL RUN** when train ≥ 300 (`--min-train`) and holdout ≥ 30 → R1 test, gate certification possible.
   - **EXPLORATORY** when 30 ≤ train < 300 and holdout ≥ 20 → reduced feature set, ridge up-weighted, output scream-labeled as non-evidence.
   - **INSUFFICIENT DATA** otherwise → deterministic stub gate, exit 0. *(current state)*
5. **Univariate screen** (when ≥40 IC rows): tertile WR tables for rsi/atrPct/adx/bbBandwidth/totalMult/atrPercentile/sessionRange/hourMult + group tables for bbState/rsiChase — with a printed multiple-comparison warning. This answers "do totalMult / rsiGate / bbState add anything" at a glance when data lands.
6. **Gate artifact** (`scripts/d4v21_avoidance_gate.js`): `CERTIFIED: true` coefficients only if R1 passes; otherwise a stub whose `d4v21Avoid()` is a pass-through (`{trade:true, certified:false, gated:false}`) — wire-safe from day 0.

### Model + no-leakage protocol (R2)

- Pure-numpy **ridge logistic regression** on P(WIN), float64, zero-init, fixed 8000 iterations — deterministic by construction (verified: two identical runs byte-equal). `class_weight=balanced` for the v2.1 run (matches the 08-10 first-pass report), `none` for the v2 recap.
- Categorical vocabulary, numeric medians/stds fit **on TRAIN only**; unseen holdout categories → all-zero; missing numerics → TRAIN median.
- **tau chosen on TRAIN only**: max TRAIN-subset WR at coverage ≥ 15%, then the *robustness tie-break* — widen to the largest coverage within 2pp of that max (a razor argmax tail is noise-ordered; validated on synthetic). v2.1 fix vs the v2 script: ridge no longer divided by n (v2's `l2/n` made regularization vanish at 5k rows).
- Honesty machinery printed every run: post-hoc holdout sweep (labeled threshold-fishing), per-day stability, best-post-hoc-point audit with multiple-comparison caveat, sklearn rank-corr cross-check, XGBoost overfit oracle.
